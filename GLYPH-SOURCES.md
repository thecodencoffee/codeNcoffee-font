# Glyph source notes

## Traced from the supplied screenshot references
- Uppercase: `A-Z`
- Lowercase: `a-z`
- Digits: `0-9`
- Symbols: `[ ] / > < + × ÷ = ! @ # ₹ ^ & * ? , ; " ' - ¿ ¡ ~ ` \\ | } { $`

## Designed completion glyphs
The following printable ASCII characters were not available as clear standalone references and were designed to fit the same squared geometric style:

`% ( ) . : _`

The space character is a metric-only blank glyph.

## Provenance
The source references are raster screenshots supplied by the project owner. The font outlines were reconstructed from those raster images; this repository does not contain the original editable source font.
