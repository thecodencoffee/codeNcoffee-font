# Glyph source notes

The font is an independent reconstruction from the raster character sheets and profile screenshots supplied by the repository owner.

## Coverage

- Uppercase Latin: A–Z
- Lowercase Latin: a–z
- Digits: 0–9
- Printable ASCII: U+0020–U+007E
- Additional glyphs:
  - U+00A1 INVERTED EXCLAMATION MARK (¡)
  - U+00BF INVERTED QUESTION MARK (¿)
  - U+00D7 MULTIPLICATION SIGN (×)
  - U+00F7 DIVISION SIGN (÷)
  - U+20B9 INDIAN RUPEE SIGN (₹)

## Provenance and limitations

The glyph atlas in proof/glyph-atlas.html renders the actual WOFF2 outlines and labels each character with its Unicode code point and character name. The screenshot references show the visual design but do not preserve the original vector control points, kerning source data, or hinting instructions. This repository contains an independent reconstruction, not the original editable font file. Glyphs that are unclear or absent in the references were completed to maintain visual consistency.
